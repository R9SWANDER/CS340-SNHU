# CS340-SNHU

I learned a lot about what it means to be a computer scientist in CS340. Throughout this course, I learned how to take a backend system, and itegrate it with a frontend system through the Dash open source framework. This is the first time I completed an application from a full-stack purspective, and I am very proud of my work. Creating and utilizing the CRUD Python Module was a very insightful part of this course. The Python Module was not only used to make working with the back end system easier, instead of using a shell command system we could use an IDE, but also taught me a lot about flexibility and reusability in code. It is very important to make code that is reusable, by making it open ended and easily customizable, so that it may be used in as many applications as possible. This not only reduces the workload on computer scientists by reusing modules, but also makes problems easier to 'patch' by lowering the absolute value of code written and used for each application.

This course was different from my other courses because of the full-stack nature of its final few weeks and assignments. Creating an application that communicated with a database and created a web app was difficult, and taught me a lot about how computer scientists troubleshoot problems for companies in the real world. Dash was a great answer for Grazioso Slavare, because all they needed was a simple way to view the data they had already obtained. Dash provides all of this functionality, and allows for the data to be viewed over the web, making it very useful for companies already using computers as part of completing the daily workload. During the creation of the dashboard, I kept in mind the end user and what they would be looking for. In the future, I will make sure to also keep this in mind. if I did not think of the end user, the pie chart details table I created likely wouldnt have made it in to the final product. This table reiterates some information stated in the pie chart, making it easy to read, while also compiling some information about the data being filtered in real time, which otherwise would not be able to be seen by the user. Making a user friendly experience is key to being successful in the computer science field.
